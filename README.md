# тихо. — список дел

Небольшое адаптивное To-Do приложение на HTML, CSS и JavaScript без сборщика и сторонних библиотек. Данные задач и оформление сохраняются в браузере.

## Запуск

Откройте `index.html` в браузере или запустите любой статический сервер в корне проекта. Для публикации подходит GitHub Pages, Netlify или Vercel.

## Возможности

- Добавление, выполнение, повторное открытие и удаление задач
- Фильтры «Все», «В планах» и «Готово»
- Локальное сохранение задач и выбора оформления
- Адаптивный интерфейс, светлая и тёмная темы
- Пустые состояния, счётчики, русские формы числительных и доступные подписи

## Использованные инструменты

Проект подготовлен с помощью OpenAI Codex. Код написан на обычных HTML, CSS и JavaScript.

## Как устроено приложение

- `index.html` — семантическая разметка и доступные названия элементов.
- `styles.css` — адаптивное оформление, темы и поддержка уменьшения анимации.
- `app.js` — состояние задач, обработчики действий и сохранение через `localStorage`.

Задачи хранятся только в текущем браузере и не отправляются на сервер. Очистка данных сайта удалит список; синхронизации между устройствами нет. При невозможности записи приложение показывает уведомление.

## Публикация

GitHub Pages публикует корень ветки `main`. После отправки нового коммита сайт обновляется автоматически. Сборка и переменные окружения не требуются.

## Работа с AI

Использован OpenAI Codex: для разработки интерфейса, логики задач, документации и настройки публикации. JavaScript проверен на синтаксические ошибки командой `node --check app.js`. На опубликованном сайте вручную проверены добавление задачи, отметка выполнения, сохранение выполненной задачи после обновления страницы, удаление и сохранение пустого списка после повторного обновления.


## Персонализация интерфейса

Кнопка «Оформление» открывает настройки: три палитры (Мел, Графит, Песок), три характера заголовка и две плотности строк. Настройки сохраняются отдельно от задач. Старый выбор тёмной темы переносится в Графит. Диалог закрывается кнопкой, клавишей Escape или нажатием за его пределами.
